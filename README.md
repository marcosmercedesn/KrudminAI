# KrudminAI

KrudminAI is a Rails engine for secure, admin-panel-first applications.

The repository includes [demo/README.md](demo/README.md), a local companion Rails application that exercises tenant-scoped tickets, policy-gated mutations, audit records, dashboards, and a read-only local assistant through the engine contracts.

The project is in its contract-definition phase. See the [project manifesto](docs/product_scope.md), [architecture](docs/architecture.md), [replacement implementation prompt pack](docs/replacement_implementation_prompt_pack.md), and [compatibility policy](docs/compatibility_policy.md) before adding runtime behavior.
