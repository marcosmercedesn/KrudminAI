# KrudminAI

KrudminAI is a Rails engine for secure, admin-panel-first applications.

The repository includes [demo/README.md](demo/README.md), a local companion Rails application that exercises tenant-scoped tickets, policy-gated mutations, audit records, dashboards, and a read-only local assistant through the engine contracts.

The project is in its contract-definition phase. See [docs/product_scope.md](docs/product_scope.md), [docs/architecture.md](docs/architecture.md), and [docs/compatibility_policy.md](docs/compatibility_policy.md) before adding runtime behavior.
