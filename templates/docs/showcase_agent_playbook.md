# Showcase Agent Playbook

Before changing showcase behavior, read the generated showcase guide and the host application's `AGENTS.md`. Keep the ticket resource on the standard query and mutation pipelines.

For each change, prove that the result excludes another tenant and a policy-denied record. Add a request or contract test for every new action, keep generated policy predicates explicit, and update the showcase manifest when a demonstrated capability changes.

Use the theme controller's `light`, `dark`, and `system` modes; do not introduce jQuery or bypass the engine's UI primitives.
